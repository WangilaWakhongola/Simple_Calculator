# Quick Start 🚀

## 30 Seconds

```bash
# Clone
git clone <repo-url>
cd simple-calculator

# Run with Docker
docker-compose up

# Or locally
npm install
npm run dev
```

## Access
http://localhost:3000

## Features
- ✅ Basic arithmetic
- ✅ Keyboard support
- ✅ Responsive design
- ✅ Lightning fast
- ✅ Beautiful UI

## Commands
```bash
npm run dev      # Start dev server
npm run build    # Build for production
npm test         # Run tests
```
